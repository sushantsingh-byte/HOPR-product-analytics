PRODUCT JOURNEY

From search to seat.

This page gives you a clean product funnel to analyse in Mixpanel or GA4.

1

Landing

User discovers HOPR and selects Find a ride or Offer a ride.

2

Search

User enters route, date and time. Search results show matching rides.

3

Ride detail

User compares driver, route, price, seats and rating.

4

Request

User requests a seat. In this practice build the request is simulated.

5

Confirmation

User reaches a confirmation state, creating a natural conversion event.

ANALYTICS QUESTIONS

What a PO should ask.

Acquisition

Which source brings users who actually request rides?

Activation

What percentage of visitors perform their first search?

Conversion

Where do users drop between search and ride request?

Retention

Do riders return for another commute within 7 or 30 days?

Engagement

Which routes and filters are used most often?

Quality

Do highly rated drivers get more profile views and requests?
